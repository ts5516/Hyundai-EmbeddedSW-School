# 리눅스 기초 및 개발환경 구축

## 1. 임베디드 리눅스 개발환경 구축 (라즈베리 파이)

### 1.1. Raspberry Pi OS 설치

1.  **Raspberry Pi Imager 다운로드**: 공식 홈페이지에서 Imager 프로그램을 다운로드하여 설치합니다.
2.  **Imager 실행 및 설정**:
    - **장치 선택**: Raspberry Pi 4
    - **운영체제 선택**: Raspberry Pi OS (64-bit)
    - **저장소 선택**: PC에 연결된 microSD 카드
3.  **OS 커스터마이징**:
    - **계정 설정**: 사용자 이름 및 비밀번호 설정.
    - **SSH 활성화**: `서비스` 탭에서 SSH를 활성화하여 원격 접속 준비.
4.  **OS 설치**: 설정 완료 후 microSD 카드에 OS 이미지를 설치(쓰기)합니다.

### 1.2. 원격 접속 방법

#### 1. UART를 이용한 시리얼 접속

- **목적**: 네트워크 연결 없이 초기 설정을 진행하거나 부팅 로그를 확인할 때 사용.
- **설정**:
  - `config.txt` 파일에 `enable_uart=1` 추가.
  - `cmdline.txt` 파일에 `console=serial0,115200` 추가.
- **연결**:
  - PC에 USB to TTL (CP2102) 드라이버 설치.
  - 라즈베리 파이의 GPIO 핀(GND, TXD0, RXD0)과 USB to TTL 모듈을 연결.
  - PC에서 `PuTTY`를 사용하여 COM 포트, 속도(115200)를 설정하고 시리얼 접속.

#### 2. SSH를 이용한 CLI 원격 접속

- **목적**: 네트워크를 통해 텍스트 기반의 명령줄 인터페이스(CLI)로 원격 제어.
- **연결 과정**:
  1.  라즈베리 파이를 유선 또는 무선 네트워크에 연결 (`sudo raspi-config`로 Wi-Fi 설정).
  2.  `ifconfig wlan0` 명령어로 할당된 IP 주소 확인.
  3.  PC에서 `PuTTY`를 실행하고 SSH를 선택한 뒤, 라즈베리 파이 IP 주소와 포트(22)를 입력하여 접속.

#### 3. VNC를 이용한 GUI 원격 접속

- **목적**: 네트워크를 통해 그래픽 사용자 인터페이스(GUI)로 원격 제어.
- **연결 과정**:
  1.  SSH로 접속하여 `sudo raspi-config` 실행.
  2.  `Interface Options` -> `VNC` 메뉴에서 VNC 서버를 활성화.
  3.  PC에 `VNC Viewer` 프로그램을 설치.
  4.  VNC Viewer에 라즈베리 파이 IP 주소를 입력하여 그래픽 환경에 접속.

## 2. 리눅스 기초

### 2.1. 쉘(Shell) 및 명령어

- **쉘(Shell)**: 사용자와 운영체제 커널 사이의 인터페이스. 키보드 명령어를 해석하여 실행합니다. (e.g., `bash`, `zsh`)
- **주요 기본 명령어**:
  | 명령어 | 기능 | 주요 옵션 / 사용 예 |
  | --- | --- | --- |
  | `pwd` | 현재 작업 디렉토리 경로 표시 | |
  | `ls` | 파일 및 디렉토리 목록 표시 | `-l` (상세 정보), `-a` (숨김 파일 포함) |
  | `cd` | 디렉토리 이동 | `cd ..` (상위), `cd ~` (홈) |
  | `cp` | 파일/디렉토리 복사 | `cp file1.txt /tmp/` |
  | `mv` | 파일/디렉토리 이동 또는 이름 변경 | `mv old_name new_name` |
  | `rm` | 파일/디렉토리 삭제 | `rm -r mydir` (디렉토리 재귀 삭제) |
  | `mkdir` | 디렉토리 생성 | `mkdir -p dir1/dir2` |
  | `touch` | 빈 파일 생성 또는 파일 시간 정보 갱신 | |
  | `cat` | 파일 내용 전체 출력 | `cat /etc/passwd` |
  | `less` | 파일 내용을 스크롤하며 보기 | |
  | `head`/`tail` | 파일의 처음/끝 10줄 출력 | |
  | `man` | 명령어 매뉴얼 페이지 보기 | `man ls` |
  | `history` | 명령어 입력 기록 보기 | `!10` (10번째 명령 재실행) |
  | `ps` | 현재 실행 중인 프로세스 목록 표시 | `ps -ef` |
  | `top`/`htop` | 시스템 리소스 사용량 실시간 모니터링 | |
  | `kill` | 프로세스에 종료 신호 전송 | `kill 1234` |
  | `df` | 디스크 사용량 표시 | `df -h` (사람이 읽기 편한 단위) |
  | `free` | 메모리 사용량 표시 | `free -m` (MB 단위) |
  | `grep` | 텍스트에서 특정 패턴 검색 | `ps -ef \| grep "bash"` |
  | `find` | 파일 및 디렉토리 검색 | `find . -name "*.log"` |

### 2.2. 패키지 관리 (Debian 기준)

- **패키지 관리자**: 소프트웨어 설치, 업데이트, 삭제, 의존성 관리를 자동화하는 도구.
- **주요 명령어**:
  - `sudo apt-get update`: 패키지 목록 갱신
  - `sudo apt install <패키지명>`: 패키지 설치
  - `sudo apt remove <패키지명>`: 패키지 삭제 (설정 파일 유지)
  - `sudo apt purge <패키지명>`: 패키지 완전 삭제 (설정 파일 포함)
  - `dpkg -l`: 설치된 패키지 목록 확인

### 2.3. 사용자와 권한

- **사용자 관리**:
  - `cat /etc/passwd`: 사용자 계정 정보 확인.
  - `whoami`, `id`: 현재 로그인한 사용자 정보 확인.
  - `sudo useradd <사용자명>`: 사용자 추가.
  - `sudo passwd <사용자명>`: 사용자 비밀번호 설정/변경.
  - `sudo usermod <옵션> <사용자명>`: 사용자 정보 수정.
  - `sudo userdel <사용자명>`: 사용자 삭제.
  - `su <사용자명>`: 사용자 계정 전환.
- **파일 권한**:
  - **구성**: `소유자(owner)`, `그룹(group)`, `기타(others)`에 대한 `읽기(r)`, `쓰기(w)`, `실행(x)` 권한.
  - `chmod <권한> <파일>`: 파일 권한 변경 (e.g., `chmod 755 script.sh`).
  - `sudo chown <소유자:그룹> <파일>`: 파일 소유자/그룹 변경.

### 2.4. 환경 변수

- **개념**: 쉘이나 시스템에서 실행되는 프로세스에 영향을 미치는 설정 값.
- **주요 환경 변수**:
  - `PATH`: 명령어 실행 파일을 찾는 경로 목록.
  - `HOME`: 현재 사용자의 홈 디렉토리 경로.
  - `USER`: 현재 로그인한 사용자 이름.
- **설정 및 확인**:
  - `export VAR="value"`: 환경 변수 설정 (자식 프로세스에 상속).
  - `echo $VAR`: 변수 값 확인.
- **영구 설정**: `~/.bashrc` 파일에 `export` 명령어를 추가하면 재부팅 후에도 변수가 유지됨.
