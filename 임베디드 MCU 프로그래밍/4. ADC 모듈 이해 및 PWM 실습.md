# ADC 모듈 이해 및 PWM 실습

## 1. ADC (Analog-to-Digital Converter)

### 1.1. ADC 기본 개념

- **정의**: 아날로그(Analog) 신호를 디지털(Digital) 값으로 변환하는 장치.
- **변환 과정**:
  1.  **샘플링 (Sampling)**: 연속적인 아날로그 신호를 특정 시간 간격으로 측정.
  2.  **양자화 (Quantization)**: 샘플링된 값을 분해능(Resolution)에 따라 이산적인 값으로 근사.
  3.  **부호화 (Encoding)**: 양자화된 값을 2진수로 변환.
- **주요 성능 지표**:
  - **분해능 (Resolution)**: 신호를 얼마나 잘게 나눌 수 있는지를 나타내는 값 (e.g., 12-bit는 4096단계). 분해능이 높을수록 정밀하지만 변환 시간이 길어짐.
  - **샘플링 속도 (Sampling Rate, SPS)**: 1초당 샘플링 횟수.
- **변환 방식**:
  - **SAR (축차 비교형)**: MSB부터 LSB까지 한 비트씩 순차적으로 비교하며 값을 결정. 범용 MCU에 널리 사용.
  - **Delta-Sigma (델타-시그마)**: 입력 신호를 평균화하여 높은 분해능을 얻는 방식. 오디오 등 정밀 측정이 필요한 분야에 사용.

### 1.2. TC375의 ADC 모듈

- **EVADC (Versatile ADC)**: SAR 방식의 다목적 ADC 모듈.
  - 12-bit 분해능, 다수의 그룹 및 채널로 구성.
  - 외부 핀(`VAREF`, `VAGND`)을 통해 기준 전압 및 측정 범위를 설정.
- **DSADC (Delta-Sigma ADC)**: 고정밀 ADC 모듈.
- **주요 레지스터 기능**:
  - **그룹 설정 (`GxANCFG`)**: 그룹별 클럭 분주 설정.
  - **큐 설정 (`GxQMRi`)**: 변환 요청 트리거 방식 설정.
  - **중재 설정 (`GxARBCFG`, `GxARBPR`)**: 여러 변환 요청의 우선순위 제어.
  - **채널 제어 (`GxCHCTRy`)**: 변환 결과의 저장 위치 및 정렬 방식 설정.
  - **결과 저장 (`GxRESy`)**: 변환된 디지털 값을 저장.

### 1.3. 실습: 가변저항으로 LED 제어

- **목표**: 가변저항의 아날로그 전압 출력을 ADC로 측정하고, 특정 전압 이상일 때 LED를 점등.
- **구현 흐름**:
  1.  `Evadc_Init()`: EVADC 모듈 활성화 및 그룹/채널 설정.
  2.  `Evadc_startConversion()`: 특정 채널의 ADC 변환을 시작.
  3.  `Evadc_readVR()`: 변환 완료 플래그(`VF`)를 확인하고, 완료 시 결과 레지스터(`RESULT`) 값을 읽어옴.
  4.  읽어온 디지털 값을 기준값(e.g., 2V에 해당하는 디지털 값)과 비교하여 LED를 제어.

## 2. PWM (Pulse Width Modulation)

### 2.1. PWM 기본 개념

- **정의 (펄스 폭 변조)**: 디지털 신호의 펄스 폭(Pulse Width)을 조절하여 평균 전압을 제어하는 기술. 아날로그 출력을 흉내 낼 때 사용.
- **주요 용어**:
  - **주기 (Period)**: 펄스가 한 번 반복되는 데 걸리는 시간. 주파수의 역수.
  - **듀티 사이클 (Duty Cycle)**: 한 주기에서 펄스가 ON(High) 상태를 유지하는 시간의 비율 (%).
    - 예시: 50% 듀티 사이클은 주기 절반 동안 ON 상태를 유지.
- **활용**: LED 밝기 조절, 모터 속도 제어 등.

### 2.2. DC 모터 제어

- **DC 모터**: 브러시를 통해 전류를 공급받아 회전하는 간단한 구조의 모터.
- **모터 드라이버 (L298P)**:
  - **역할**: 저전력 MCU가 고전력 모터를 안전하게 제어할 수 있도록 중간에서 전류/전압을 증폭.
  - **제어 신호**: 방향(Direction), 브레이크(Brake), 속도(PWM) 신호를 통해 모터를 제어.

### 2.3. TC375의 GTM (Generic Timer Module)

- **정의**: Bosch에서 개발한 고성능 타이머 모듈로, 정밀한 PWM 신호 생성 및 입력 신호 처리가 가능.
- **주요 서브 모듈**:
  - **CMU (Clock Management Unit)**: GTM에서 사용할 다양한 클럭을 생성 및 관리.
  - **ATOM (ARU-connected TOM)**: 복잡하고 유연한 PWM 신호 생성을 담당.
- **ATOM PWM 생성 원리 (SOMP 모드)**:
  - 기준 카운터(`CN0`)가 주기적으로 증가/감소하며 신호의 **주기**를 결정.
  - 비교 레지스터(`CM1`) 값이 카운터 값과 일치할 때 출력 신호를 반전시켜 **듀티 사이클**을 조절.

### 2.4. 실습: PWM을 이용한 모터 제어

- **목표**: 듀티 사이클을 조절하여 DC 모터의 속도를 제어.
- **라이브러리**: **iLLD (Infineon Low Level Driver)**를 사용하여 복잡한 레지스터 설정을 추상화.
- **구현 흐름**:
  1.  `GtmAtomPwm_Init()`: GTM 모듈을 활성화하고 ATOM 채널과 핀을 PWM 출력으로 설정.
  2.  `GtmAtomPwm_SetDutyCycle(duty)`: `duty` 값(0~100)을 입력받아 ATOM의 비교 레지스터(CM1) 값을 변경하여 듀티 사이클을 조절.
  3.  가감속 제어: `for` 또는 `while` 루프 내에서 `duty` 값을 점진적으로 변경하며 `SetDutyCycle` 함수를 호출.
  4.  시리얼 통신 제어: UART로 특정 문자('w', 's' 등)를 수신하여 `duty` 값을 변경하고 모터를 제어.
